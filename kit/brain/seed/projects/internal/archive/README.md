# projects/internal/archive/

Closed internal projects, moved here whole from `projects/internal/<project>/` with `uv run tools/brain/brain-state.py archive <project>`, only on the owner's explicit request; `unarchive` brings one back. An archived project leaves every command, the web interface and the dashboards; `uv run tools/brain/brain-state.py find <term> --archived` searches it. The tool rewrites the links.
